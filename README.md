# Studylog — 주간 게시글 예약 (API 심사용)

비상업적 개인 스터디 운영자가 **사이트에서 버튼을 한 번 눌러** 다음 일요일 오전 9시에 게시할 월~토 날짜별 게시글 **6개를 예약**하는 프로그램을 개발하고 있습니다.

## 의도한 기능
1. 운영자가 웹사이트에서 게시 예정 일요일을 선택합니다.
2. **게시글 6개 예약하기**를 누르면 서버에 날짜별 글 6개와 발행 예정일을 저장합니다.
3. 일요일 오전 9시(한국 시간)에 승인된 BAND Open API로 해당 6개 게시글을 작성합니다.

예시: 26/11/30 월, 26/12/01 화, ... 26/12/05 토

**댓글 조회, 댓글 작성, 회원 이름 및 댓글 내용 수집은 하지 않습니다.** 광고, 홍보 또는 불특정 밴드에 반복 전송하는 용도가 아닙니다. 본인 운영 밴드 한 곳에 한정합니다.

## 현재 개발 및 심사 상태
- 시연 페이지: https://u-sumin.github.io/studylog/
- 일정 계산 및 BAND 글쓰기 코드가 존재하지만, 실제 **버튼→예약 저장 서버**는 아직 연결되지 않았습니다.
- 따라서 웹사이트의 예약 버튼은 비활성화되어 있습니다.
- BAND API 승인을 받지 못했기 때문에 실제 게시 기능을 비활성화합니다.
- 공식 BAND 글쓰기 API에는 '예약 게시물' 생성 기능이 없으며, 예약 시점에 별도 서버에서 글쓰기 API를 호출할 계획입니다.
- GitHub Actions의 예약 실행 시각은 지연될 수 있습니다.

## 보안
BAND 인증키는 공개 웹페이지에 넣지 않고 서버 비밀정보로 관리합니다. API 승인 이후에도 제삼자의 밴드 회원 정보는 읽거나 저장하지 않습니다.
