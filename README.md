# Studylog

비상업적 개인 스터디 밴드를 위한 주간 게시글 및 휴가 댓글 집계 자동화 프로젝트입니다.

## 예정된 기능
- 일요일 오전 9시: 그 주 월요일부터 토요일까지 날짜별 게시글 6개 작성
- 월요일~토요일 오전 7시 20분: **해당 날짜 게시글의 댓글만** 조회하고 `반휴`, `월휴`, `시험휴` 분류
- 결과는 해당 게시글에 댓글 **한 개**로 등록하고 중복 등록 방지
- 결과 예시:

```
반휴: 김철수
월휴: 홍길동
시험휴: -
```

## 현재 상태
네이버 밴드 API 승인 전입니다. 시연 화면은 예시 데이터만 사용하며 실제 밴드에 글이나 댓글을 전송하지 않습니다.

API가 승인된 경우에만 GitHub Actions Secrets에 인증 정보를 등록하여 실제 자동 게시 및 댓글 집계를 실행하도록 구성할 예정입니다.

> **주의:** API 토큰, 앱 비밀키, 로그인 정보, 실제 스터디 회원 데이터는 GitHub 저장소나 공개 시연 웹페이지에 넣지 않습니다.
