Studylog 개인정보 처리 안내

Studylog는 개인 스터디 운영자가 지정한 밴드에 날짜별 게시글 6개를 예약 발행하기 위해 개발 중인 비상업적 서비스입니다.

현재 공개 시연 웹페이지는 선택한 일요일로 날짜만 계산합니다. BAND 계정 정보, 댓글 또는 회원 정보를 조회하거나 수집하지 않습니다.

향후 운영자 인증과 예약 저장 서버가 마련되면, 예약 발행을 위해 글 내용과 게시 예정 시각, 예약 상태를 처리할 예정입니다. 실제 BAND Open API 호출은 공식 승인 이후에만 활성화합니다.

댓글 조회, 댓글 작성, 회원명 수집 기능은 제공하지 않습니다. BAND API 인증키는 공개 페이지에 저장하지 않습니다.
