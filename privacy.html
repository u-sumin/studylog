Studylog 개인정보 처리 안내

Studylog은 비상업적 개인 스터디 밴드 관리용 프로젝트입니다.

현재 공개 시연 페이지는 가상 데이터만 사용하며 실제 밴드 회원 정보, 로그인 정보 및 인증 토큰을 수집하지 않습니다.

밴드 API 사용이 승인되면 운영자 계정으로 지정한 밴드의 날짜별 게시글과 휴가 신청 댓글, 댓글 작성자의 표시 이름 및 작성 시각을 조회하여 해당 날짜의 집계 결과 댓글을 생성하는 용도로만 사용할 예정입니다. 인증 정보는 공개 웹페이지에 포함하지 않습니다.

실제 운영 전에 승인 범위와 데이터 처리 방침을 다시 확인합니다.
