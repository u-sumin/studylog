주간 게시글 6개 예약

개인 스터디 운영자가 관리하는 밴드 한 곳에 날짜별 게시글 6개를 준비하는 비상업적 프로젝트입니다. 댓글과 회원 정보를 조회하거나 수집하지 않습니다.

예약할 날짜 설정

일요일 오전 9:00 (한국 시간)
GitHub Actions는 정각 실행을 보장하지 않습니다.

예약 대상 게시글

이 버튼은 아직 실제 예약을 생성하지 않습니다. 승인 후 운영자 인증과 예약 저장 서버를 연결해야 활성화됩니다.

서비스 작동 방식

1. 예약
운영자가 웹사이트에서 다음 일요일을 선택하고 게시글 6개 예약하기를 누릅니다.

2. 예약 보관
서버가 날짜별 제목과 발행 예정일을 저장합니다. 아직 구현 및 연결 전입니다.

3. 자동 발행
일요일 오전 9시에 서버가 승인된 BAND Open API를 통해 게시글 6개를 작성합니다.

현재 단계: 공개 기능 시연

실제 BAND API 사용은 승인 전까지 비활성화되어 있습니다. 또한 BAND의 예약 목록에 등록하는 것이 아니라, 예약된 시각에 API로 작성하는 방식입니다.

개인정보 처리 안내

Studylog는 BAND 공식 서비스가 아닌 독립적인 개인 스터디 관리 도구입니다.
