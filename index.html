예약할 게시글 6개를
미리 보고 수정하세요

일요일 오전 9시에 작성할 월요일부터 토요일까지의 게시글을 준비할 수 있어요. 날짜별 내용을 수정하면 미리보기에 바로 반영됩니다.

1. 예약 일정 선택

발행 예정 시각
선택한 일요일 오전 9:00 (한국 시간)

현재는 시연 단계입니다. 글은 밴드에 전송되지 않으며 예약도 저장되지 않습니다.

2. 게시글 선택

월요일부터 토요일까지 총 6개 게시글

3. 내용 편집과 미리보기

변경 내용은 이 브라우저에만 저장됩니다.

4. 공통 문구 일괄 적용

6개 글에 같은 안내를 추가하고 싶다면 입력하세요. 각 글의 첫 줄에는 해당 날짜가 들어갑니다.

적용하면 기존 6개 게시글의 내용을 덮어씁니다. 적용 전 확인창이 표시됩니다.

게시글 6개 전체 내용 미리보기

5. 게시글 6개 예약하기

API 승인 및 서버 연결 대기 중

현재 수정한 내용은 브라우저에 임시 저장되는 초안입니다. 실제 예약은 이루어지지 않습니다. 향후 예약 서버와 BAND 글쓰기 API가 연결되면, 버튼 한 번으로 6개 게시글을 예약하고 일요일에 자동 발행하도록 구현할 예정입니다.

참고: 밴드 예약 게시글 목록에 등록하는 방식이 아니라, 예정 시각에 승인된 BAND API로 작성하는 방식입니다. 자동 실행이 지연될 수 있습니다.
